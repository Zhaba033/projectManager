# Менеджер проектов
## Описание
Менеджер проектов - это удобный способ контролировать выполнение проекта в группе. На сайте можно:
- Создавать новые проекты или просматривать уже существующие
- В каждом проекте создавать новые задачи, браться за выполнение тех, которые уже поставлены и закрывать их
- Каждый пользователь видит, кто какую задачу выполняет, может оставлять комментарии к задачам
